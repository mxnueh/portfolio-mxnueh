# portfolio-mxnueh

Portafolio personal de Enmanuel Nunez Matias, desarrollador Full Stack.

## 1. Descripción

Sitio web estático que presenta proyectos, tecnologías y certificaciones. Está construido con HTML, CSS y JavaScript, sin frameworks.

## 2. Secciones

- **Projects:** proyectos destacados — POI Administrator (administración de contenido y usuarios), Floppy (monitor inteligente de nivel de agua) y Calculator (calculadora con operaciones aritméticas).
- **Featured Technologies:** lenguajes y herramientas con los que trabajo.
- **Certifications:** certificaciones recientes.

## 3. Tecnologías

- HTML · CSS · JavaScript

## 4. Uso

No requiere instalación. Abre `index.html` en el navegador, o sirve la carpeta:

```bash
python -m http.server 8000
```

## 5. Estructura

```
portfolio-mxnueh/
├── index.html
├── css/style.css
├── js/back.js
├── assets/        # Logos, imágenes y certificados
└── Wireframes/    # Wireframes de los proyectos mostrados
```
